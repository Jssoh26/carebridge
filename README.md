# CareBridge

**One connected caregiver journey.**

Live prototype: https://jssoh26.github.io/carebridge/

CareBridge is a student prototype (CC0007) for family caregivers of older adults in Singapore. It brings existing caregiver support into one journey:

- **GrantMatch** — Smart Grant Finder
- **CareBreak** — Short-Term Care Booking
- **Kopi-Talk** — Multilingual Voice Assistant
- **CareTransition** — Hospital-to-Home Planner

All people, providers, prices and records are fictional demo data. Singpass, provider availability and hospital information are simulated; no real systems are connected.

This repository holds the built website. On a phone, open the link and choose **Add to Home Screen** to install it as an app.
